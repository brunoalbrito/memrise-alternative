# Quickstart: Validate Nano Banana 2 Lite Integration

**Status**: Ready for Testing | **Date**: 2026-10-21 | **Updated**: 2026-10-21

## Prerequisites

1. **Get Nano Banana 2 Lite API Key**
   - **Option A** (Free, Recommended): Google AI Studio
     - Visit https://aistudio.google.com/apikey
     - Create API key (no billing required for free tier)
     - Copy key to clipboard
   - **Option B** (Alternative Providers): EvoLink, FAL.ai, Cloudflare, or ApiFrame.ai
     - Sign up and create API key from their dashboard
     - Same API endpoint and format

2. **Get Google AI API Key** (for text suggestions)
   - Already set up in MemBetter; required for Auto-fill
   - Verify it is saved in "Connect AI" dialog

3. **Clone and Set Up MemBetter**
   ```bash
   git clone <repo>
   cd membetter
   pnpm install
   ```

## Scenario 1: Save and View Nano Banana 2 Lite Key

### Setup
- App is running (`pnpm dev`)
- No Nano Banana key saved yet

### Steps
1. Open **Settings** → **Connect AI**
2. Verify section "Nano Banana 2 Lite API key (for images)" is visible
3. Paste Nano Banana API key into text field
4. Click **Save**

### Expected Outcome
- ✅ Key is masked on screen (e.g., `••••••xyz7` shows last 4)
- ✅ Message shows "Nano Banana 2 Lite connected."
- ✅ Input field clears
- ✅ Button changes to **Remove key**

### Teardown
- Reload app (`Cmd+R` or browser refresh)
- Verify key is still saved and masked

## Scenario 3: Generate Image with Nano Banana 2 Lite

### Setup
- Nano Banana key is saved
- Google AI key is saved
- App is running
- A course with words and sentences is loaded (e.g., `pnpm dev:samples`)

### Steps
1. Open a word in the course (e.g., "humid")
2. Click **Auto-fill** button
3. Wait for suggestions to load
4. In the **Image** section, wait for "Creating image..." message
5. Verify image appears (should be generated by Nano Banana)
6. Optionally click **New image** to regenerate
7. Click **Apply** to attach image to word

### Expected Outcome
- ✅ Image appears within ~6-8 seconds (4s API + 2-4s network latency)
- ✅ Image caption shows "Made for: [selected sentence]"
- ✅ Image is attached to word's Images list
- ✅ Reload app; image persists
- ✅ No requests sent to Pollinations API (verify with network tab)

### Network Verification
- Open **DevTools** → **Network** tab
- Filter by `generativelanguage.googleapis.com` requests
- Verify request goes to `generativelanguage.googleapis.com/v1beta/models/gemini-3.1-flash-lite-image:generateContent?key=...` (Google's official endpoint)
- Verify query parameter includes API key: `?key=YOUR_API_KEY`
- Verify request body includes: `contents[0].parts[0].text` (prompt), `generationConfig.aspectRatio: "1:1"`, `generationConfig.outputMimeType: "image/jpeg"`
- Verify response includes `candidates[0].content.parts[0].inlineData.data` (base64-encoded image)
- Verify no requests sent to Pollinations or EvoLink endpoints

## Key API Endpoint Details

- **Endpoint**: `POST https://generativelanguage.googleapis.com/v1beta/models/gemini-3.1-flash-lite-image:generateContent?key=YOUR_API_KEY`
- **Auth**: API key in query parameter (from https://aistudio.google.com/apikey)
- **Request**: `{contents[0].parts[0].text: prompt, generationConfig: {aspectRatio: "1:1", outputMimeType: "image/jpeg"}}`
- **Response**: Base64 image in `candidates[0].content.parts[0].inlineData.data`
- **Speed**: ~4 seconds per image
- **Rate Limit**: 100 images/minute, 10 concurrent max (free tier)
